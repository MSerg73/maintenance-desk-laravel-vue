# Maintenance Desk — Laravel + Vue

Maintenance Desk is a compact portfolio application for equipment maintenance workflows. It models an industrial maintenance register with role-based access, equipment records, maintenance requests, controlled status transitions, assignment rules, filters, pagination, validation, and automated quality gates.

The repository is intended as a reviewable Laravel + Vue code sample rather than a production deployment.

## Stack

- PHP 8.5
- Laravel 13
- Vue 3
- TypeScript
- Inertia 3
- Wayfinder typed Laravel routes/actions
- SQLite for the local demo
- Pest
- PHPStan / Larastan
- Laravel Pint

## Domain

### Equipment

Equipment fields:

- name
- technical code
- location
- status

Statuses:

- `active`
- `maintenance`
- `out_of_service`

The register supports search, status filtering, pagination, CRUD operations, and deletion protection when maintenance history exists.

### Maintenance requests

A request contains equipment, short title, detailed description, priority, workflow status, creator, optional assignee, and timestamps.

Priorities:

- `low`
- `normal`
- `high`
- `critical`

Workflow:

```text
NEW -> IN_PROGRESS -> DONE -> CLOSED
```

Skipping workflow states and transitions after `CLOSED` are rejected.

## Role-based access

| Capability                   | Operator | Engineer | Admin |
| ---------------------------- | :------: | :------: | :---: |
| View equipment               |   Yes    |   Yes    |  Yes  |
| Create/edit/delete equipment |    No    |    No    |  Yes  |
| View maintenance requests    |   Yes    |   Yes    |  Yes  |
| Create an unassigned request |   Yes    |   Yes    |  Yes  |
| Edit request details         |    No    |   Yes    |  Yes  |
| Advance request workflow     |    No    |   Yes    |  Yes  |
| Assign/change assignee       |    No    |    No    |  Yes  |

Authorization is enforced server-side through Laravel Policies/Gates. Vue capability flags only control presentation and are not the security boundary.

## Dashboard

The dashboard shows:

- equipment totals by state;
- maintenance request totals by workflow status;
- open high/critical requests;
- five most recent maintenance requests.

## Local setup

Requirements:

- PHP 8.5+
- Composer
- Node.js 24 LTS+
- npm

Install dependencies:

```bash
composer install
npm install
```

Create `.env` from `.env.example`, generate an application key, and make sure `database/database.sqlite` exists.

Windows PowerShell example:

```powershell
Copy-Item .env.example .env
php artisan key:generate
if (-not (Test-Path database/database.sqlite)) {
    New-Item database/database.sqlite -ItemType File
}
```

Build a clean demo database:

```bash
php artisan migrate:fresh --seed
```

Start the application:

```bash
composer run dev
```

## Design notes

- Laravel Policies are the authorization boundary.
- Workflow transitions are separate from ordinary request edits.
- Assignment is a distinct administrative capability.
- Request status and priority use backed enums.
- Equipment deletion is blocked when maintenance history exists.
- Role values are protected from ordinary mass assignment.
- Frontend routes/actions are generated by Wayfinder.
- Tests cover positive flows and negative authorization scenarios.
